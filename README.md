Project Description:

Aura & Bean is a modern multi-page coffee shop website created to present a premium and welcoming coffee shop experience. The website allows users to explore different sections of the coffee shop, including information about the brand, coffee menu, drinks, photo gallery, and reservation options.

The website consists of seven connected pages: Home, About, Menu, Drinks, Gallery, Reservation, and Register. Each page has a consistent navigation bar and visual style, making it easy for users to move between different sections.

The Home page introduces the coffee shop with a hero section and a background image. The Menu and Drinks pages present the available products, while the Gallery page displays coffee shop images in a responsive layout. The Reservation page provides a form where users can enter their information and make a reservation.

The website was developed using HTML5, CSS3, Bootstrap 5, and Google Fonts. CSS Flexbox and Grid were used for page layouts, while Bootstrap and media queries were used to make the website responsive.

For the endterm project we used our midterm website as the base and added interactivity with JavaScript and jQuery. Now users can search and filter the menu, register with a validated form, open gallery photos in a lightbox, and manage the drinks list in a table (add, edit, delete). All JavaScript code is in js/script.js.

The final website works on desktop, tablet, and mobile devices and is published online using GitHub Pages.

- Required field checks for name, email, password and message
- Email format check with RegEx
- Password strength indicator (weak, medium, strong)
- Password confirmation check
- Real-time feedback with Bootstrap is-valid / is-invalid and alerts
- Form is not submitted if validation fails
- Real-time search bar on the Menu page (case-insensitive)
- Category filter buttons (All, Coffee, Signature, Desserts) that work together with search
- Dynamic drinks table with CRUD on the Drinks page (add, read, inline edit, delete with confirm)
- Image gallery with lightbox, next/previous arrows and keyboard arrows
